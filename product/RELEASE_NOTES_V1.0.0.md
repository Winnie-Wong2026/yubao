# 聿宝星球 V1.0.0 发布说明

- 版本：`V1.0.0`
- 类型：家庭试用版
- 发布日期：2026-08-16
- 数据结构版本：`3`

## 发布基线

- 孩子端 PWA 与家长端 Web 使用独立入口。
- 学习任务由家长创建，孩子自行完成，家长确认后发放星币。
- 数字奖励采用整套人物、整张背景和完整宠物的独立图层替换。
- 现实奖励由家长配置、审核和兑现。
- 孩子端支持星球、任务、日历、装扮、商店和点击声音。

## 初始状态

- 星币余额和冻结余额均为 `0`。
- 任务、日历记录、星币流水和兑换记录为空。
- 人物、背景和宠物恢复默认装扮。
- 已确认的奖励配置、价格、上架状态和上传素材保留。

## 使用边界

- 仅用于单家庭、单孩子的本地环境。
- 当前无云端同步、互联网账号和消息推送。
- 家长 PIN 是本地家庭保护措施，不是互联网生产级认证。
