# 聿宝星球 V1.2.6（家庭试用版）

当前产品版本：`V1.2.6`；数据结构版本：`7`。两者独立管理。

## 入口

- 孩子端 PWA：`http://127.0.0.1:8787/product/child/`
- 家长端 Web：`http://127.0.0.1:8787/product/parent/`
- 家长 PIN：`2580`
- 家庭码：`381624`

两个入口相互独立。孩子端没有家长管理入口；家长端需要 PIN 验证。

## 启动

双击根目录的 `start-yubao.command`，或在根目录执行：

```bash
npm start
```

默认从 8787 端口开始；端口占用时会自动寻找后续可用端口，实际地址以终端输出为准。

## 初始状态

- 星币余额：0，冻结：0。
- 学习任务、日历记录、星币流水和兑换记录：空。
- 默认拥有并使用：默认学习套装、星光阁楼、星星猫。
- 已确认的数字奖励与现实奖励配置保留并正常上架。

家长端“设置”中可以清空使用记录。清空前必须输入页面随机生成的 4 位验证码；任务完成照片会删除，奖励配置、任务提示图和奖励素材会保留。

## 已实现闭环

1. 家长按语文、数学、英语、阅读、体育等快捷学科创建学习任务，支持一次任务和每天重复任务。
2. 新建或编辑任务时可直接拍照或从相册选择一张任务提示图；图片会实时预览、自动压缩，并同步到孩子任务卡片和完成弹窗。
3. 每天重复任务支持“仅今天”“今天和以后”和“明天起”三个修改范围，任务提示图与拍照规则随当天实例保存快照，不覆盖历史记录。
4. 完成时间支持快捷选项和自定义填写；任务管理可按待完成、待确认、已确认筛选。
5. 家长可将完成照片设为可选、必拍或不用拍；新任务默认可选，旧任务升级后保持不用拍。
6. 孩子可调用相机或相册选择一张完成照片，图片在浏览器中转为最长边1600像素的JPEG后与任务原子提交。
7. 家长确认或退回任务，退回后再次提交会保留每一次完成照片和处理结果；确认后只发放一次星币。
8. 家长端首页、任务管理、待处理和任务记录共用统一详情抽屉，明确区分“要做什么”和“完成情况”。
9. 家长端记录页分为任务记录、奖励兑换和星币账本，任务记录支持时间、状态和学科筛选。
10. 每日任务跨日后恢复为当天待办，上一天的任务要求、照片规则和提交记录保留在历史快照中。
11. 今日任务全部确认后，孩子端首页显示“今天全部完成”和“看看今天的收获”。
12. 孩子端提供星球日历，可按月查看全部完成、等待确认、部分完成、未完成和无任务状态。
13. 点击日历日期可查看当天任务、学科、状态和实际到账星币；历史保存在 `taskDayRecords`。
14. 家长新增和编辑人物套装、背景主题、宠物伙伴；可修改名称、说明、价格、上架状态，并可选替换静态图或短视频，也可选择孩子端展示静态图或短视频。
15. 孩子商店支持未购买数字奖励预览；预览临时替换人物、背景或宠物单层，支持短视频，不改变当前装备。
16. 孩子兑换和装备数字奖励；人物、背景、宠物三个图层独立保存。
17. 内置奇妙萌可甜心魔法与哈利波特魔法学院两组人物/背景奖励；素材采用原创设计，不复刻原作角色或标志。
18. 家长新增现实奖励，支持六类内置配图和家庭自定义上传。
19. 家长管理、孩子列表和兑换申请共用保存后的同一 `imageUrl`。
20. 现实奖励申请冻结星币；同意后等待兑现；兑现后扣款；拒绝后解冻。
21. 任务、钱包、装备、奖励、兑换和流水保存到 `product/data/state.json`，服务重启不丢失。
22. 孩子首页只统计今日任务；往日未完成任务进入独立待处理清单，已确认任务保留在日历和家长记录中，不再混入今日进度。

## 当前技术边界

- 这是家庭局域网本地服务，没有云端账号、互联网同步和消息推送。
- 家长 PIN 适用于本地家庭环境，不等同于互联网生产环境安全认证。
- 孩子端 PWA 壳已完成；非 localhost 的 iPad 安装需要后续配置 HTTPS。
- 短视频优先使用 MP4、WebM；macOS 本地服务上传 MOV 时会尝试自动转码为网页可播放的 M4V。孩子端只在奖励 `mediaMode=motion` 且“减少动画”关闭时播放短视频；播放失败时回落到核心静态图。
- 上传文件保存在 `product/uploads/`；任务提示图最大10MB，孩子完成照片服务端最终限制6MB，静态素材最大16MB，短视频最大64MB。
- 星球日历的确认规则和实现说明：`product/星球日历设计方案-待确认.md`。
