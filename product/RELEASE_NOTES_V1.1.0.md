# 聿宝星球 V1.1.0 发布说明

- 版本：`V1.1.0`
- 类型：家庭试用版
- 发布日期：2026-08-16
- 数据结构版本：`3`

## 本次完善

- 家长可编辑待完成或被退回的学习任务，包括学科、名称、说明、循环方式、完成时间和星币奖励。
- 孩子已提交或家长已确认的任务会锁定，避免事后修改任务与星币历史。
- 家长可编辑现实奖励的名称、类别、说明、价格、剩余次数、有效期、兑换间隔、备注、配图和上架状态。
- 已经提交的现实奖励申请继续保留申请当时的名称、配图与星币价格，不受后续编辑影响。
- 现实奖励剩余次数为零时，孩子端明确显示“已兑完”。

## 数据兼容

- 沿用数据结构版本 `3`，现有家庭数据无需清空或迁移。
- 新增编辑只更新奖励配置或尚未提交的任务，不改写既有星币流水和已完成记录。
