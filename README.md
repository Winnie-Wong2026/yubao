# yubao

`yubao` 是“聿宝星球”家庭学习计划产品的代码仓库。产品面向小学二年级孩子，包含独立的孩子端 PWA 与家长端 Web。

当前版本：`V1.2.6`（家庭试用版）

## 主要功能

- 家长创建一次性或每日重复的学习任务。
- 家长可为任务拍摄或选择一张提示图，帮助孩子看懂任务；提示图不是完成凭证。
- 家长可按任务设置完成照片为“可以拍照”“必须拍照”或“不用拍照”。
- 孩子自行提交任务，可拍摄一张完成照片；家长确认后发放星币。
- 孩子通过星币兑换整套人物、整张背景、完整宠物和家庭现实奖励。
- 人物、背景、宠物使用独立图层，切换其中一项不会改变另外两项。
- 孩子端提供星球、任务、日历、装扮、商店和点击声音。
- 家长端提供统一任务详情、待处理事项、任务记录、奖励兑换、星币账本和家庭设置。

## 本地运行

需要 Node.js 20 或更高版本，不需要安装第三方依赖。

```bash
npm start
```

默认入口：

- 孩子端：`http://127.0.0.1:8787/product/child/`
- 家长端：`http://127.0.0.1:8787/product/parent/`

端口被占用时，服务会自动尝试后续端口。首次启动会在 `product/data/state.json` 创建本地家庭数据，该文件不会提交到 GitHub。

## 版本与数据

- 产品版本：`product/version.json`
- 发布说明：`product/RELEASE_NOTES_V1.2.6.md`
- 运行数据：`product/data/state.json`
- 家庭上传素材：`product/uploads/`

运行数据与家庭上传内容仅保存在本机。家长端清空使用记录时会删除任务完成照片，同时保留奖励配置、任务提示图和奖励素材。

## 当前边界

- 单家庭、单孩子的本地使用版本。
- 暂无云端同步、互联网账号和消息推送。
- 家长 PIN 是本地家庭保护措施，不是互联网生产级认证。
- 短视频字段已经预留，V1 运行界面优先使用静态图。

本项目未声明开源许可证，素材与代码仅供仓库所有者的家庭项目使用。

## 验证

- `npm test` 运行任务提示图、完成照片流程、上传安全与回滚、历史记录与迁移四组隔离测试。
- 测试数据和图片使用临时 `YUBAO_DATA_DIR`、`YUBAO_UPLOAD_DIR`，不会写入家庭正式数据。
